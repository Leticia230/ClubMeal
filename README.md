# ClubMeal

## Link
> [Página web](https://leticia230.github.io/ClubMeal/)

## 🎯 Objetivo
O **ClubMeal** tem como objetivo oferecer um aplicativo simples e interativa para **organização de refeições**, permitindo que usuários explorem cardápios, receitas e permite que estudantes informem se vão comer ou não.

## ⚙️ Funcionalidades do App
- **Cadastro de usuários**: permite criar perfis para acessar conteúdos personalizados.  
- **Login e autenticação**: sistema de acesso seguro para cada usuário.  
- **Gerenciamento de cardápio**: adicionar, editar e visualizar receitas.
